# Customer Churn Analysis Dashboard

## Project Overview
This project focuses on analysing customer churn using Power BI. The objective is to understand customer retention patterns, identify factors associated with customer churn, and present insights through an interactive dashboard.

## Dataset
- Dataset: Churn Modelling – Customer Churn Records
- Source: Kaggle
- Records: 10,000 customers
- Key attributes: Geography, Gender, Age, Tenure, Balance, Credit Score, Number of Products, IsActiveMember and Exited.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## Key Performance Indicators
- Total Customers
- Churned Customers
- Retained Customers
- Customer Churn Rate

## Dashboard Analysis
The dashboard explores:
- Customer churn by geography
- Customer churn by age group
- Customer churn by number of products
- Customer churn by active membership
- Overall customer retention and churn distribution

## Interactive Features
- Geography filter
- Gender filter
- Card Type filter
- Active Membership filter

## Project Objective
To use data visualisation and analysis to understand customer behaviour, identify churn patterns and support data-driven customer retention strategies.
